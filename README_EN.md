**Minimalist Sudoku** is an embedded Sudoku game plugin meticulously designed for developers. Whether you're waiting for a long build process or stuck on a complex bug, you can start a brainstorming session without ever leaving your IDE.

---

## 🌟 Introduction

Minimalist Sudoku seamlessly integrates into the IntelliJ IDEA interface, providing a clean and minimalist gaming experience through the Tool Window. It's not just a small tool to relax; it's also a perfect companion for improving logical thinking skills.

### Core Highlights:
- **Seamless Integration**: As part of the IDE, it can be opened or hidden at any time without interfering with your normal development workflow.
- **Minimalist Design**: Pursues a pure Sudoku experience with a clean interface and no redundant distractions.
- **Smart Adaptation**: Automatically adapts to the IDE's dark/light themes to ensure visual consistency.
- **Multi-language Support**: Native support for Chinese, English, Japanese, and Korean.

## ✨ Features

- **Timer**: Real-time recording of game duration to challenge your limits.
- **Smart Hints**: Get hints with one click when you're stuck to help you break through difficulties.
- **Pause/Resume**: Pause the game at any time to handle urgent development tasks and continue the challenge when you return.
- **One-click Restart**: Not satisfied with the current layout? Generate a new Sudoku board at any time.
- **Error Highlighting**: Real-time display of conflicting numbers to help you quickly correct errors.

---

## 🛠️ Installation

1. Open IntelliJ IDEA.
2. Go to `Settings` (Windows/Linux) or `Settings/Preferences` (macOS).
3. Select `Plugins` and search for **Minimalist Sudoku**.
4. Click `Install` and restart or activate as prompted.
5. After installation, find the **Minimalist Sudoku** icon in the right toolbar to start.
