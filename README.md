**Minimalist Sudoku (极简数独)** 是一款专为开发者精心设计的内嵌式数独游戏插件。无论你是在等待漫长的构建过程，还是在为一个复杂的 Bug 苦思冥想，你都可以在不离开 IDE 的情况下，开启一场大脑风暴。

---

## 🌟 应用介绍

极简数独无缝集成在 IntelliJ IDEA 界面中，通过 Tool Window（工具窗口）提供清爽、极简的游戏体验。它不仅是一款放松心情的小工具，更是提升逻辑思维能力的绝佳伴侣。

### 核心亮点：
- **无缝集成**：作为 IDE 的一部分，随时开启或隐藏，不干扰正常开发流程。
- **极简设计**：追求纯粹的数独体验，界面简洁，无冗余干扰。
- **智能适配**：自动适配 IDE 的深色/浅色主题，确保视觉一致性。
- **多语言支持**：原生支持中文、英文、日文和韩文。

---

## ✨ 功能特性

- **计时功能**：实时记录游戏时长，挑战自己的极限。
- **智能提示**：遇到卡壳时，一键获取提示，助你突破难关。
- **暂停/恢复**：随时暂停游戏，处理紧急开发任务，回来后继续挑战。
- **一键重开**：不满意当前的布局？随时生成新的数独棋盘。
- **错误高亮**：实时显示冲突数字，帮助你快速纠错。

---

## 🛠️ 安装方式

1. 打开 IntelliJ IDEA。
2. 进入 `Settings` (Windows/Linux) 或 `Settings/Preferences` (macOS)。
3. 选择 `Plugins` 并在搜索框中输入 **Minimalist Sudoku**。
4. 点击 `Install` 并根据提示重启或激活。
5. 安装完成后，在右侧工具栏找到 **极简数独** 图标即可开始。
